# Notes for AI agents working on this repo

## Color palette (required going forward)

Use this palette for all new UI work and when touching existing styles. See `spec.md` for full usage guidance.

- Background: Ethereal Ivory — `#E4E4DE`
- Surface: Sophisticated Sage — `#C4C5BA`
- Primary Text: Eerie Black — `#1B1B1B`
- Accent: Muted Moss — `#595F39`

Do not introduce other colors for new work. If a design requires a color outside this palette, flag it instead of guessing, and update `spec.md` / `decision.md` if the palette changes.

See `decision.md` for why this palette was adopted.
